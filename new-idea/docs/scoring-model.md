# 评分模型

> 三专家 × 八维 × 子权重 → 加权聚合 → 最终评分  
> 模拟大厂真实新品评审流程

---

## 一、八维评分体系（总分 100）

| 维度 | 权重 | 说明 | 评分标准（0-10） |
|------|------|------|-----------------|
| 市场机会 (marketOpp) | 15% | TAM/SAM/SOM 评估 | 0=无市场; 5=小众; 8=细分赛道百亿级; 10=千亿级且有增长 |
| 痛点强度 (pain) | 15% | 用户痛点频率×严重度 | 0=无感; 5=偶尔不便; 8=高频高痛; 10=日用刚需且抱怨集中 |
| 趋势增长率 (trend) | 12% | 搜索/社媒/销量 YoY 增长 | 0=下降; 5=持平; 7=年增15%+; 10=年增50%+或爆发前夜 |
| 技术可行性 (techFeas) | 10% | 制造成熟度 / 供应链可获取性 | 0=不可行; 5=需重大研发; 8=现有技术可组合; 10=供应链成熟即开即用 |
| 竞争壁垒 (competitiveMoat) | 10% | 差异化可持续性 / 护城河 | 0=红海无壁垒; 5=短期先发优势; 8=技术/品牌/渠道垄断; 10=网络效应+转换成本双高 |
| 单位经济模型 (unitEcon) | 10% | 毛利 / 回收期 | 0=亏损不可持续; 5=薄利长回收; 8=毛利率40%+且18月内回收; 10=高毛利+短回收期 |
| 战略契合度 (strategicFit) | 8% | 公司核心能力匹配 | 0=完全不相关; 5=相关需新建能力; 8=与现有产线高度协同; 10=核心战略必争 |
| 用户体验潜力 (uxPotential) | 10% | 预期 NPS 提升幅度 | 0=无改善; 5=小幅提升; 8=可显著提升NPS 20+; 10=品类定义级体验 |
| 执行风险 (execRisk) | 5% | 合规/监管/排期 | 0=极高风险(合规红线/排期不可控); 5=中等风险; 10=低风险 |
| 创新溢价 (innovation) | 5% | 市场新颖度 / 先发优势 | 0=无差异跟随; 5=局部创新; 8=品类首创; 10=定义新赛道 |

---

## 二、三专家子权重

不同专家在其擅长领域获得不同的权重放大系数（用于加权时调节评分影响力）。

| 维度 | 产品专家 | 市场投资专家 | 用户专家 |
|------|---------|------------|---------|
| marketOpp | ×1.0 | **×2.0** | ×1.0 |
| pain | ×1.0 | ×1.0 | **×2.5** |
| trend | ×1.0 | **×2.0** | ×1.0 |
| techFeas | **×2.0** | ×1.0 | ×1.0 |
| competitiveMoat | ×1.5 | **×2.0** | ×1.0 |
| unitEcon | ×1.0 | **×2.0** | ×1.0 |
| strategicFit | ×1.0 | ×1.0 | ×1.0 |
| uxPotential | **×2.0** | ×1.0 | **×2.5** |
| execRisk | ×1.0 | ×1.0 | ×1.0 |
| innovation | **×2.0** | ×1.0 | ×1.0 |

---

## 三、最终分计算公式

```
每个专家在各维度的子分 = 维度分值 × 维度权重 × 专家子权重
最终分 = Σ(三专家各维度子分) / Σ(三专家各维度的"权重×子权重") × 100

简化描述：
最终分 = 三专家八维加权聚合，归一化到 0-100
```

### 举例（ID-001）

假设市场机会维度：
- 产品专家打 7 分，权重=15%，子权重=1.0 → 子分=7×15×1.0=105
- 市场专家打 8 分，权重=15%，子权重=2.0 → 子分=8×15×2.0=240
- 用户专家打 6 分，权重=15%，子权重=1.0 → 子分=6×15×1.0=90

以此类推十维加总，再除以归一化分母。

## 四、评分阈值与输出

| 等级 | 条件 | 输出位置 |
|------|------|---------|
| ⭐ TOP5 需求 | >90 分 | TOP5 需求分析区（硬性 5 个） |
| 📋 功能需求清单 | >75 分 | 功能需求清单区（评分倒序） |
| 📝 观察池 | 60-75 分 | 不进入报告正文（≥2 个 Tier 趋势证据后可升级） |
| 🔕 不录入 | <60 分 | 不进入报告，归档至 ideas-pool 供未来参考 |

## 五、专家角色

### 产品专家
- 评估重心：技术可行性 · UX 潜力 · 创新溢价 · 竞争壁垒
- 典型思维：这个能不能做出来？体验能不能做好？有没有创新突破？
- 出题倾向：供应链成本、工艺成熟度、良品率、专利风险

### 市场投资专家
- 评估重心：市场机会 · 趋势 · 竞争壁垒 · 单位经济
- 典型思维：这个市场有多大？在增长吗？竞争格局怎样？能赚钱吗？
- 出题倾向：TAM、增长率、竞争强度、毛利率、回收期

### 用户专家
- 评估重心：痛点强度 · UX 潜力
- 典型思维：用户真的需要这个吗？痛点有多深？用了会好多少？
- 出题倾向：ＮPS 预估、竞品满意率、抱怨集中度、使用频率
