# 数据源全景地图

## 概述

本文档定义 3C 竞品分析中所有可用的数据来源、接入方式、优先级与使用指引。

## Tier 0 — 官方一手数据（最高优先级）

### 品牌官网 & 规格书
| 来源 | URL 模式 | 适用品类 | 内容 |
|------|----------|----------|------|
| Apple 官网 | `apple.com/cn/` | 耳机/手表/音箱 | 产品页 + 技术规格 |
| Samsung 官网 | `samsung.com/cn/` | 耳机/手表 | 产品页 + 规格表 |
| Sony 官网 | `sony.com.cn/` | 耳机/音箱 | WH/WF 系列参数 |
| 华为官网 | `consumer.huawei.com/cn/` | 耳机/手表/音箱 | FreeBuds/Watch/Sound |
| 小米官网 | `mi.com/` | 耳机/手表/音箱 | Buds/Watch/Sound |
| OPPO/vivo/荣耀 | 各自官网 | 耳机/手表 | Enco/Watch/Earbuds |

### 固件更新日志
- Apple firmware updates（`support.apple.com`）
- Samsung Galaxy Buds firmware changelog
- Sony Headphones Connect app release notes
- 各品牌官方社区 Beta 版公告

### 认证数据库
- **CCC 认证查询**：`cx.cnca.cn` 中国强制性产品认证
- **SRRC 型号核准**：无线电发射设备型号核准
- **工信部入网许可**：`jwxk.miit.gov.cn`
- **FCC ID**：`fccid.io` 美国联邦通信委员会

| iFixit | `ifixit.com` | 拆解/可维修性评分 |

### 🇨🇳 B站 3C UP主（Tier 1 · 新增）
| UP主类型 | 内容特点 | 获取方式 |
|----------|----------|----------|
| 数码评测类 | 深度参数对比、频响实测 | 搜索：`{产品名} 评测` |
| 拆机/维修类 | 内部结构、芯片型号 | 搜索：`{产品名} 拆解` |
| 对比横评类 | 同品类多产品对比 | 搜索：`{品类} 横评` |
| 使用体验类 | 长期使用报告 | 搜索：`{产品名} 长期使用` |

B站证据提取标准：
- 标注视频 URL + 时间戳
- 关键帧截图（图表、对比画面）
- 注明 UP 主粉丝量 / 过往内容可信度
- 区分"商单"与"独立评测"（有商单标注的需交叉验证）

### 🇨🇳 小红书测评（Tier 1 · 新增）
| 内容类型 | 特点 | 获取方式 |
|----------|------|----------|
| 真实开箱 | 普通用户第一手体验 | 搜索：`{产品名} 开箱` |
| 硬核测评 | 参数党/发烧友深度分析 | 搜索：`{产品名} 深度测评` |
| 对比笔记 | 同品类多产品使用对比 | 搜索：`{产品名} 对比` |
| 长期体验 | 使用 1-3 个月后反馈 | 搜索：`{产品名} 使用感受` |

小红书证据提取标准：
- 标注笔记 URL + 发布日期
- 注意区分"素人分享"与"品牌合作"（平台会标注）
- 同一产品至少 3 篇独立笔记交叉验证
- 截图保留（平台可能删帖）

### 🇨🇳 抖音测评（Tier 1 · 新增）
| 内容类型 | 特点 | 获取方式 |
|----------|------|----------|
| 数码博主测评 | 短视频形式功能展示 | 搜索：`{产品名} 测评` |
| 对比测试 | 降噪/续航等实测对比 | 搜索：`{产品名} vs` |
| 使用技巧 | 隐藏功能/使用技巧分享 | 搜索：`{产品名} 技巧` |
| 踩坑避雷 | 问题/缺陷曝光 | 搜索：`{产品名} 避雷` |

抖音证据提取标准：
- 标注视频 URL
- 注意区分内容创作者与品牌官方号
- 实测数据需注明测试条件
- 短视频信息密度低，优先提取结论性内容

## Tier 2 — 电商 & 社区用户声音

### 电商平台
| 平台 | URL | 核心数据 |
|------|-----|----------|
| 京东 | `jd.com` | 评价 + 问答 + 参数 + 价格走势 |
| 天猫 | `tmall.com` | 评价 + 参数 + 价格 |
| 亚马逊 | `amazon.com/.cn/.jp` | 全球评价 + 问答 + 参数 |
| 什么值得买 | `smzdm.com` | 好价 + 评测 + 用户讨论 |

电商证据提取标准：
- 标注评论数、好评率、差评关键词
- 差评按有用数排序后人工筛选
- 区分"已购"与"未购"评论
- 关注追评（反映长期使用问题）

### 用户社区
| 平台 | URL | 适用场景 |
|------|-----|----------|
| Reddit | `reddit.com/r/headphones` `r/AndroidWear` 等 | 国际用户真实反馈 |
| 知乎 | `zhihu.com` | 深度使用体验、行业分析 |
| 贴吧 | `tieba.baidu.com` | 产品专属贴吧讨论 |
| 酷安 | `coolapk.com` | 数码发烧友社区 |
| HiFi 论坛 | 耳机大家坛等 | 音频发烧友深度讨论 |

社区证据提取标准：
- 标注帖子 URL + 点赞/回复数
- 区分"粉丝拥护"与"客观评价"
- 负面反馈权重高于正面（用户更倾向分享负面体验）

## 数据源优先级规则

1. **同一事实存在多个来源** → 取 Tier 最高的
2. **Tier 1 存在争议** → 回溯 Tier 0 官方数据核实
3. **用户声音类（Tier 2）与其他冲突** → 以实测/官方为准，标注用户偏差
4. **中国特供产品** → 优先中文源（B站/小红书/抖音/京东）
5. **国际同步产品** → 中英文源平等对待，交叉验证

## 采集工作流

```
1. 确定品类 + 竞品列表
2. 创建 raw/ 子目录
3. 按 Tier 0→1→2→3 依次搜索采集
4. 每份原始证据用标准文件名归档
5. 提取关键数据到 evidence.json
6. 标记每条证据的核验状态到 verification.json
```
